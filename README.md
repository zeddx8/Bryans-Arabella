# Bryans Arabella Collection

- `backend/`  Node + Express + MySQL API (see backend/README.md)
- `frontend/` React + Vite storefront and admin console (see frontend/README.md)
- `docs/` product, technical and design documents (start with docs/README.md)
- `DEPLOY.md` step by step guide to put the site online

Run locally: start MySQL, then `cd backend && npm run db:setup && npm run dev`, then `cd frontend && npm run dev`.
